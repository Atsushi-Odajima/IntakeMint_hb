Reminder（リマインド）
========================================

■ リマインドの基本

・案件の「準備完了の目標日」を基準に、まだ揃っていない項目だけを書いたリマインド文面を自動で作ります。
・目標日が設定されていない案件では、自動のリマインドは作られません
  （「未提出項目で下書きを作成」ボタンによる手動作成は可能です）。
・ステータスが「下書き」「Ready」「開始済み」「アーカイブ」「キャンセル」の案件には作られません。
・バックグラウンド処理が15分おきに確認しています（サーバーが起動している間だけ動きます）。


■ 3つの段階（フォーム編集画面「リマインド」タブで設定）

・期限前（before）… 「期限の何日前（カンマ区切り）」で指定。既定は3日前
・当日（due）……… 「期限当日にも作成する」。既定ON
・期限超過（overdue）… 「期限超過後 何日ごと」（既定3日ごと）、「超過後の最大回数」（既定3回）

期限超過の段階では、担当者に「期限超過」の通知も届きます。


■ 未提出の項目だけを書きます

文面には、次のものだけが入ります。
・未提出 / 一部提出（例：商品・サービス画像：一部提出（3/5））/ 差し戻し（差し戻し理由つき）の必須項目
・回答待ちの追加質問
揃っていないものが何もなければ、リマインドは作られません。

件名の例：【送信者名】案件名：ご提出のお願い（残り3件）


■ 重複しません

・同じ案件・同じ段階・同じ目標日のリマインドは1回しか作られません。
・目標日を変更すると、新しい目標日を基準に改めて段階が判定されます。


■ 送信しない時間帯とタイムゾーン

・「送信しない時間帯」（既定 21:00〜08:00）は送信を見送り、時間帯が明けてから送ります。
・時刻の判定は案件のタイムゾーンで行います。案件作成時に、組織の設定
  （設定 → ブランド・組織 →「タイムゾーン（リマインド・深夜帯判定）」、既定 Asia/Tokyo）が使われます。


■ 既定は「下書き → 担当者が承認して送信」

・「送信方法」の既定は「下書きを作成し、担当者が承認して送信（推奨）」です。
・案件詳細「リマインド」タブで、下書きの内容を確認し、次のどれかを押します。
  - 承認して送信（新しいリンク付き）… 新しい共有リンクを発行して本文の最後に追加して送信
  - リンクなしで送信 ……………………… 本文のまま送信
  - 取消
・送信前に「○○ へ送信します。よろしいですか？」と確認が出ます。
・クライアントのメールアドレスが未設定の案件では送信できません（「案件の設定」タブで登録できます）。
・承認・送信には「リマインド送信」権限（Owner / Admin / Manager）が必要です。


■ 自動送信モード（任意）

・「送信方法」を「自動送信」にすると、担当者の承認なしで送信キューに入ります。
・送信の直前に、案件がすでに Ready / 開始済み / アーカイブ / キャンセルになっていないかを再確認し、
  該当すれば送信しません。
・お客様に届く文面を確認できないため、運用に慣れるまでは「下書き」モードをおすすめします。


■ メール送信の設定（重要）

・初期設定のメールプロバイダは「ローカル記録（outbox-local）」です。
  承認・送信しても、実際のメールは送られず、「設定 → メール送信履歴」に記録されるだけです。
・実際に送るには、運用者が次の3つをすべて設定する必要があります。
    EMAIL_PROVIDER=resend
    EMAIL_API_KEY=（Resend の API キー）
    EMAIL_ALLOW_REAL_SEND=true
  あわせて EMAIL_FROM（送信元アドレス）を、送信ドメインの認証を済ませたアドレスにしてください。
・送信に失敗した場合は最大4回まで再試行し、それでも失敗すると状態が「failed」になり、
  担当者に「メール送信に失敗しました」の通知が届きます。
・送信者名は「設定 → ブランド・組織」の「送信者名（メール・ポータルに表示）」です。


■ よくある質問

Q. リマインドが作られません
A. 目標日が入っているか、案件が「下書き」（リンク未発行）になっていないか、リマインドが有効か、
   未提出の項目が残っているかを確認してください。

Q. 送信したのにお客様に届きません
A. 初期設定ではメールは実送信されません。上記「メール送信の設定」を行ってください。

Q. MCP（Claude Code など）からリマインドを送れますか？
A. 下書きの作成（draft_reminder）まではできますが、送信はアプリ上で担当者が承認する必要があります。
