最初のIntakeを作る
========================================

ここでは「フォームを作る → 公開する → 案件を作る → 共有リンクを発行 → お客様に送る」
までの流れを、画面のボタン名どおりに説明します。
（例として「Web制作（コーポレートサイト）」サンプルを使います）


■ 全体の流れ

  1. サンプルを選んでフォームを作る
  2. フォームを編集する（質問・条件分岐・必要項目など）
  3. 「公開（新バージョン）」で公開する
  4. 公開したフォームから案件を作る
  5. 「共有リンクを発行」でクライアント用リンクを作る
  6. リンクをコピーして、ご自身でお客様に送る


■ 1. サンプルからフォームを作る

・左のメニュー「フォーム」を開き、「＋ フォームを作る」を押します。
・業種別サンプルの一覧が出ます。使いたいサンプルを押すと、そのコピーが下書きとして作られます。
  - Web制作（コーポレートサイト） / EC立ち上げ・出店支援 / SNS運用代行 / 動画制作 /
    採用・人事（応募書類回収） / コンサルティング開始 / 税務・会計資料の回収 /
    不動産（物件情報・必要書類） / 汎用ヒアリング
・ゼロから作りたい場合は「白紙から作る」を選びます。
・サンプルは出発点です。業種ごとに法的に必要な書類をすべて網羅していることは保証しません。


■ 2. フォームを編集する

フォームの編集画面には次のタブがあります。

・セクション・質問 …… 質問文、種類、必須、「初期状態は非表示（条件で表示）」、補足説明など
・条件分岐 ……………… 回答に応じた表示/非表示/必須化（「質問と条件分岐.txt」参照）
・必要項目 ……………… 進捗の分母になる項目。質問の項目とファイルの項目があります
・Ready条件 …………… サインオフ必須、ファイルの承認必須、AI候補の扱いなど
・リマインド …………… 期限前/当日/超過、送信方法、送信しない時間帯
・パック構成 …………… 案件開始パックの各セクションに入れる質問、Handoffプロファイル
・JSON ………………… 上級者向け。定義をJSONで直接編集（保存時にサーバーで検証）

編集したら「下書き保存」を押します。エラー（存在しない質問を参照している、
条件分岐が循環している等）があると、画面上部に赤い枠で表示されます。


■ 3. 公開する（新しいバージョンになります）

・「公開（新バージョン）」を押すと、v1、v2…と新しいバージョンとして公開されます。
・公開済みのバージョンは上書きされません。フォームを直して再公開すると新バージョンになり、
  既存の案件は作成時のバージョンのまま動きます（途中で質問が変わってお客様が混乱しないため）。
・条件分岐が循環しているとボタンが押せず、公開できません。
・公開には「公開」権限（Owner / Admin / Manager）が必要です。Editor は下書き保存まで可能です。


■ 4. 案件を作る

・メニュー「案件」またはダッシュボードで「＋ 新しい案件」を押します。
・入力項目
  - フォーム（テンプレート）：公開済みのものだけ選べます（名前の横にバージョン表示）
  - クライアント名（必須）
  - クライアントのメール（任意・リマインド用）
  - 案件名（必須）
  - 準備完了の目標日（任意。自動リマインドはこの日付を基準に作られます）
・「作成する」を押すと案件の詳細画面が開きます。この時点のステータスは「下書き」です。


■ 5. 共有リンクを発行する

・案件詳細の右上「共有リンクを発行」を押します。
・緑の枠に「クライアント用リンク（この画面でのみ表示されます／○月○日まで有効）」が出ます。
・「コピー」でリンクをコピーしてください。
・このリンクは一度だけ表示されます。画面を閉じると再表示できません
  （サーバーにはリンクそのものではなく、照合用の値だけを保存しているためです）。
  見失った場合は「共有リンク」タブの「再発行（既存を無効化）」で作り直してください。
・既定の有効期限は14日です。「共有リンク」タブでは3〜90日から選んで発行できます（詳しくは「Clientへ送る.txt」）。
・リンクを発行すると、案件のステータスは「送信済み」になります。


■ 6. お客様へ送る（ご自身で送ります）

・IntakeMint はこのリンクを自動でメール送信しません。
  内容を確認のうえ、普段お使いのメール・チャット等でお客様へお送りください。
・送付文の例
  「〇〇の制作開始にあたり、必要な情報と素材のご提出をお願いします。
    下記リンクから、途中保存しながらご入力いただけます（アカウント登録は不要です）。
    有効期限：〇月〇日」


■ このあとの流れ

・お客様が回答・アップロードすると、ステータスが「回答中」に変わり、通知が届きます。
・全項目が提出されると「内部確認待ち」になります。
・担当者がファイルを承認し、AI確認候補を処理し、「内部確認OK（サインオフ）」を押すと
  「Ready（開始可能）」になります。
・Readyになったら「案件開始パック」タブでパックを生成し、仕事を始めましょう。
  「仕事を開始（開始済みにする）」でステータスを「開始済み」にできます。
