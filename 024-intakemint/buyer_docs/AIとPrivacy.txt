AIとPrivacy（AIとプライバシー）
========================================

■ 初期設定のAIは「ローカル判定」（外部送信なし）

・初期設定（AI_PROVIDER=local）では、AIの確認候補はサーバー内のルールベースの判定
  （ローカル判定 / local-heuristic）で作られます。
・お客様の回答やファイルが、外部のAIサービスに送られることはありません。API費用もかかりません。
・起動時のログに「ai=local-heuristic」と表示されます。


■ 外部AI（Anthropic Claude）を使う場合

外部AIが使われるのは、運用者が次の3つをすべて設定した場合だけです。
    AI_PROVIDER=anthropic
    AI_API_KEY=（Anthropic の APIキー）
    AI_ALLOW_EXTERNAL=true
（任意で AI_MODEL。既定は claude-haiku-4-5-20251001）

・AI_ALLOW_EXTERNAL=true がない限り、APIキーを設定しても外部には送られません。
・外部AIを有効にする前に、必ずお客様（回答者）から外部AIでの処理について同意を得てください。
  IntakeMint には同意を取得・記録する画面はありません。同意の取得と記録は運用者の責任です
  （利用規約・プライバシーポリシー・個別の合意書などで行ってください）。
・外部AIに送られる内容
  - 表示中の質問への回答（条件分岐で非表示の回答は送りません）
  - AI処理を除外していないテキスト形式のファイル（TXT / CSV 等）から抽出した文字
  - フォームの質問定義
・送られないもの
  - 画像・PDF などのファイル本体（ファイルの分類は、ファイル名・形式などの情報だけで社内で判定します）
  - AI処理を除外したファイル
・外部AIの結果も「候補」として保存されるだけで、自動で回答を変えたり要件を確定したりしません。
・外部AIの応答の形式が正しくない場合は、その回はローカル判定の結果を使います。
  通信エラーやAPIエラーの場合は、その回は外部送信なしのローカル判定に自動で切り替わります。
・外部AIの送信量は1案件ごとの回答量に比例します。費用は「運用コスト.txt」を参照してください。


■ AIのON/OFFは3段階

1) 組織全体 … 設定 → AIとプライバシー「組織全体でAI機能を使う」
2) 案件ごと … 案件詳細 → 設定タブ「この案件でAIを使う」（案件作成時は組織の設定を引き継ぎます）
3) ファイルごと … 担当者は「AI除外」ボタン、お客様はアップロード時の
   「この資料はAI処理に使わない（機密資料など）」にチェック

・組織または案件で AI を OFF にすると、AIプロバイダ（ローカル判定を含む）への呼び出しは0になり、
  AI用に抽出したテキスト（AIインデックス）もすぐに削除されます。
・ファイルを AI除外にすると、そのファイルの抽出テキストが削除されます。
・組織の AI を ON に戻しても、案件ごとに OFF にした案件は OFF のままです。
・案件ごとの「AI OFF」は案件詳細の上部にバッジで表示されます。


■ AIの利用状況を確認する

・設定 → AIとプライバシー →「AI呼び出し履歴（集計）」で、プロバイダ、外部送信の有無、用途、
  回数、文字数を確認できます。
・すべてのAI呼び出しは記録され、案件の監査ログにも残ります。


■ データの削除

・案件詳細 → 設定タブ「案件を完全削除」で、その案件の回答・ファイル（保存先の実体も）・
  AIインデックス・検索インデックス・AI候補・パックなどを完全に削除します。元に戻せません。
  監査ログには「削除した」という記録だけが残り、内容は残りません。
・アーカイブ・キャンセルした案件は、組織の「アーカイブ済み案件の保存期間（日）」（既定365日、30〜3650日）
  を過ぎると、自動的に同じ方法で削除されます。


■ 回答を分析ツールに使いません

・お客様の回答本文を、アクセス解析・広告・製品分析などの目的に流用することはありません。
・IntakeMint 自体に外部のアクセス解析ツールは組み込まれていません。


■ 集めてはいけない情報（フォームを作るときの注意）

次のような情報は、IntakeMint のフォームやファイルで集めないでください。
・パスワード、ログイン情報、二段階認証コード
  （SNS運用代行サンプルには「パスワードはこのフォームに入力しないことを確認しました」という確認欄があります）
・マイナンバー（個人番号）
・病歴・診断書などの医療情報、その他の要配慮個人情報
・クレジットカード番号、銀行口座の暗証番号
・本人確認書類の真正性確認（KYC）が必要な情報
どうしても必要な場合は、それぞれの法令・ガイドラインに沿った専用の仕組みを使ってください。


■ そのほかの配慮

・参考サイトURLのタイトル取得（サーバーから外部URLへアクセスする機能）は既定でOFFです。
  ONにしても、社内ネットワークやクラウドのメタデータアドレスへのアクセスは常に拒否されます。
・ファイルを開くURLは5分で失効します。共有リンクには有効期限があります。
・バックアップZIPには個人情報・業務資料が含まれます。暗号化されたストレージで保管してください。
・社内でのアクセス権は5段階（Owner / Admin / Manager / Editor / Viewer）。お客様は共有リンクの案件にだけアクセスできます。
