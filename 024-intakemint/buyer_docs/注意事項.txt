注意事項
========================================

ご利用・販売・本番公開の前に、必ずお読みください。


■ 保証しないこと

・法律・医療・税務・本人確認（KYC）に関する正確性や適法性は保証しません。
  IntakeMint は情報と書類を集めて整理するツールであり、専門家の判断の代わりにはなりません。
・業種別サンプル（Web制作、EC、SNS運用代行、動画、採用・人事、コンサル、税務・会計、不動産、汎用）は
  出発点の例です。各業種で法的に必要な書類・項目をすべて網羅していることは保証しません。
  （採用サンプルは本人確認の真正性を、税務・不動産サンプルは必要書類の網羅性や法的要件を保証しません）
・OCR・AIの精度は保証しません。AIの指摘・分類・抽出はすべて「候補」であり、見落としや誤りがあり得ます。
  PDF・画像の文字抽出（OCR / Vision）は現バージョンでは未接続です。
・Ready判定は、設定したルールに基づく機械的な判定です。業務上「本当に開始してよいか」の最終判断は、
  担当者が行ってください。
・運用コストの試算は目安です。実際の請求額を保証しません。


■ 名称・商標について

・「IntakeMint」という名称は、正式な商標調査（クリアランス）を行っていません。
  簡易的な Web 検索・npm 確認のみで、ドメイン・GitHub・商標データベース（J-PlatPat / USPTO 等）は未確認です。
・販売・公開の前に、名称の使用可否を必ず確認し、必要に応じて名称を変更してください。


■ 個人情報と外部AI

・実際のお客様のデータを、同意なく外部のAIサービスに送らないでください。
  外部AIは運用者が明示的に有効化した場合のみ動きますが、有効化する前に回答者の同意を得てください
  （IntakeMint には同意の取得・記録機能はありません）。
・パスワード、マイナンバー、医療情報、クレジットカード番号などは集めないでください。
・お客様に対するプライバシーポリシー・利用規約の整備は、運用者の責任で行ってください。


■ 現時点で行っていないこと

・有料サービスとの契約、本番環境へのデプロイは行っていません。
・実際のメール送信は接続していません（初期設定はローカル記録のみ）。
・Google Drive などの外部サービス連携（コネクタ）は接続していません。
・スマホの実機での動作確認は行っていません（エミュレーションのみ。「スマホ-PWA.txt」参照）。


■ 制限事項

・ファイル保存は、初期設定ではサーバーのローカルディスク（単一ノード）です。
  複数台のサーバーで動かす場合や、サーバーの入れ替えに備える場合は、S3互換ストレージ
  （S3_ENDPOINT / S3_BUCKET / S3_REGION / S3_ACCESS_KEY_ID / S3_SECRET_ACCESS_KEY）を設定してください。
・S3互換ストレージのアダプタは、実際のバケットに対するテストを行っていません。
  本番で使う前に、アップロード・ダウンロード・削除・バックアップ・復元を検証してください。
・ウイルス対策の ClamAV は同梱していません。初期設定は EICAR テストファイルの検出のみです。
・Google Drive / Dropbox / OneDrive / Gmail / Slack などのコネクタは、将来対応予定のアダプタ（設計のみ）です。
  現バージョンで使えるのは、お客様ポータルからのアップロードと、各種エクスポートだけです。
・組み込みの PGlite は開発・デモ・単一プロセス向けです。本番や MCP との同時利用は PostgreSQL を使ってください。
  PGLITE_DIR を指定しない場合、データはメモリ上にしかなく、再起動で消えます。
・本番モード（npm start）は SIGNING_SECRET（32文字以上）が必須で、ログイン Cookie は Secure 属性になります。
  HTTPS で公開してください。
・本番モードでは新規登録が既定で無効です（最初の Owner 作成時のみ ALLOW_SIGNUP=true を使います）。
・メール確認付きリンクの確認コードは、実際のメール送信を設定するまでお客様に届きません
  （設定 → メール送信履歴で本文を確認し、電話等で伝えることは可能です）。
・ホワイトラベル（独自ドメイン・IntakeMint表記の非表示）は未対応です（Pro版候補）。
・アーカイブ・キャンセルした案件は、保存期間（既定365日）を過ぎると自動で削除されます。
・バックアップZIPは組織全体を一度に作るため、ファイルが非常に多い組織ではメモリを多く使います。
  復元時の展開サイズの上限は 2GB です。
・バックグラウンド処理（AIチェック、リマインド、メール送信、保存期間の削除）は、サーバーの
  プロセス内で動きます。サーバーが止まっている間は実行されません。
・npm start は tsx（TypeScript実行ツール。dependencies に含まれます）で起動します。


■ サンプルデータについて

・SEED_SAMPLE=true で作られる「Sample Creative Studio（架空）」と「株式会社サンプル」などは架空のデータです。
・サンプルアカウント（owner@sample-creative.example / sample-demo-password）は公開情報です。
  本番環境では SEED_SAMPLE を有効にしないでください。
