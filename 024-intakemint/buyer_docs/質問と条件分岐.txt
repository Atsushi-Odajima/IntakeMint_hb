質問と条件分岐
========================================

■ 質問の種類（14種類）

フォーム編集画面「セクション・質問」タブの「種類」で選べます。

・短文 ……………… 1行のテキスト（既定 500文字まで）
・長文 ……………… 複数行のテキスト（既定 10,000文字まで）
・メール …………… メールアドレス形式をチェック
・電話 ……………… 電話番号形式をチェック（数字・+・-・()・空白、7〜20文字）
・URL ……………… http:// または https:// で始まるURLのみ
・数値 ……………… 最小・最大を指定可能
・日付 ……………… 存在しない日付（2月30日など）はエラー
・単一選択 ………… 選択肢から1つ（選択肢は1行に「値=表示名」）
・複数選択 ………… 選択肢から複数（最小・最大個数も指定可能）
・はい/いいえ ……… 「はい」か「いいえ」
・ファイル ………… 「提出先のファイル項目」とつないで、その位置にアップロード欄を出します
・画像 ……………… ファイルと同じ。写真・画像向け
・繰り返し項目 …… 例：参考サイトを「URL」「参考にしたい点」のセットで複数行入力
・同意チェック …… チェックが入っていないと未回答扱い

各質問には「必須」「初期状態は非表示（条件で表示）」「補足説明」を設定できます。
入力チェックはお客様の画面でもすぐに行われ、最終的にはサーバー側でも必ず再チェックされます。


■ 条件分岐ルールとは

「もし〇〇の回答が△△なら、□□を表示する/必須にする」というルールです。
「条件分岐」タブの「＋ ルールを追加」から作ります。

条件（もし）
・＝ / ≠ / を含む / のいずれか / ＞ / ≧ / ＜ / ≦ / 回答あり / 未回答

アクション（→）は4種類
・表示 ………… 対象の質問・必要項目を表示する
・非表示 ……… 対象を隠す
・必須にする … 対象を必須にする
・任意にする … 対象の必須を外す

対象には「質問」だけでなく「必要項目」も選べます。1つのルールに複数のアクションを
「＋ アクション」で追加できます。複数条件の組み合わせ（すべて満たす / いずれか / 否定）は
JSONタブで編集できます。


■ 例：Web制作サンプル

・「サイトに必要な機能」で「ネット販売（EC）」を選ぶと
  → 「掲載する商品数」「希望する決済方法」を表示して必須に、
    「配送方法・送料の考え方」「会員登録機能は必要ですか？」を表示
・「採用」を選ぶと
  → 「募集職種」を表示して必須に、「応募から面接までの流れ」を表示


■ 循環（ループ）は公開できません

・AがBを表示し、BがAを表示する…のように、ルールが自分自身に戻ってくる状態を「循環」と呼びます。
・循環があると編集画面に「条件分岐が循環しています：A → B → A（公開できません）」と表示され、
  「公開（新バージョン）」ボタンが押せなくなります。サーバー側でも公開時に必ずチェックします。
・他にも、存在しない質問・項目を対象にしている、選択式なのに選択肢がない、IDが重複している、
  といったエラーがあると公開できません。


■ 非表示になった質問の回答はどうなる？

・お客様が一度回答した後で、条件が変わって質問が非表示になった場合、
  その回答は「保持」されますが、進捗・Ready判定・案件開始パックからは「除外」されます。
・再び表示されれば、保持していた回答がそのまま使われます。
・担当者の「回答」タブでは、非表示の質問も薄く表示され「（非表示）」と付きます。
・CSV出力では visible 列に「no(hidden)」と出ます。
・非表示の質問への回答は、他のルールの条件判定にも使われません（連鎖的に非表示になります）。
・条件で非表示になった必要項目は「対象外」として、進捗の分母から外れます。


■ AIが提案したルールは「下書き」

・ルールには「有効」と「下書き」の状態があります。AI由来（origin: ai）のルールや下書きルールは、
  担当者が「有効化」を押すまで一切動作しません。
・下書きルールがあると、編集画面に「ルール ○○ は下書き（AI提案など）のため無効です。
  確認して有効化してください」という警告が出ます（警告なので公開は可能です）。
・なお現バージョンには、AIがルールを自動で作成する機能はありません。
  下書きルールは JSON 取り込みなどで追加された場合に表示されます。


■ 画面での作成時のちょっとした注意

・「のいずれか」は値をカンマ区切りで入力します（例：ec,recruit）。いずれかが選ばれていれば成立します。
・複数選択の質問に「＝」を使うと「その選択肢が選ばれているとき」に成立します（「を含む」と同じ意味）。
・ルールを変えたら「下書き保存」→「公開（新バージョン）」を忘れずに。
  公開するまで新しいルールはお客様の画面に反映されません。
