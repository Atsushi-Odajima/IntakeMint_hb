スマホ・PWA
========================================

■ スマホでの利用

・お客様用の画面（共有リンク）は、スマホでの入力を前提に作っています。
  選択肢は大きめのボタン、メール・電話・数値は専用キーボードが出ます。
・担当者用の画面（ダッシュボード・案件・設定）もスマホ幅で表示できます。
・PWA（ホーム画面に追加して、アプリのように使える仕組み）に対応しています。
・ホーム画面への追加・オフライン用の仕組み（Service Worker）は、HTTPS で公開されたサイトでのみ動きます
  （パソコンで localhost を開く場合を除く）。本番は必ず HTTPS で公開してください。


■ ホーム画面に追加する

iPhone / iPad（Safari）
  1) Safari で IntakeMint を開く
  2) 画面下（iPad は上）の「共有」ボタンを押す
  3) 「ホーム画面に追加」を選び、「追加」を押す

Android（Chrome）
  1) Chrome で IntakeMint を開く
  2) 右上のメニュー（︙）を押す
  3) 「アプリをインストール」または「ホーム画面に追加」を選ぶ
     （画面下に「インストール」の案内が出ることもあります）

・ホーム画面のアプリは、担当者用画面（/app/）から始まる設定です。
・お客様には、ホーム画面への追加ではなく「届いたリンクを開く」か「ブラウザのブックマーク」で
  アクセスしていただくのが確実です（ホーム画面アプリから開くと、共有リンクではなく
  担当者用のログイン画面が開く場合があります）。


■ カメラ・写真からのアップロード

・ファイル項目の「ファイルを選択 / 撮影」を押すと、スマホでは
  「写真ライブラリ」「写真を撮る（カメラ）」「ファイルを選択」などの選択肢が出ます
  （画像形式を受け付ける項目の場合）。表示される選択肢は端末・OSのバージョンによって異なります。
・複数枚まとめて選択できます。
・iPhone の写真（HEIC / HEIF）は、受付形式に heic / heif が含まれている項目なら、そのまま提出できます
  （サンプルの画像項目は jpg / jpeg / png / webp / heic / heif を受け付けます）。
・項目ごとの最大サイズを超えるファイルは、送信前に画面でお知らせします。


■ オフラインのとき（電波が悪いとき）

・画面上部に「オフラインです — 回答は端末に下書き保存されます。ファイル提出と最終送信は接続後に行えます。」
  と表示されます。
・オフライン中にできること
  - 回答の入力（端末内に下書きとして保存されます）
  - 「保存して終了」（端末に下書き保存。接続が戻ると自動で送信されます）
・オフライン中にできないこと
  - ファイルのアップロード（ボタンが押せなくなります）
  - 「送信する」（最終送信）
  - 追加質問への回答
・オフライン中の下書きは、まだサーバーには届いていません。接続が戻って
  「自動保存しました（時刻）」と表示されるまでは、提出は確定していません。
・アプリの画面部分だけを端末に保存しており、回答やファイルなどのデータを
  オフライン用に保存・キューすることはありません。


■ iPhone（iOS Safari）の注意点

・Safari のタブで開いている場合、7日間そのサイトを使わないと、端末に保存されたデータ
  （下書き等）が削除されることがあります（WebKit のストレージ方針。ホーム画面に追加した
  Webアプリは、この7日の上限の対象外とされています）。
・端末の空き容量が少ない場合なども、保存データが削除される可能性があります。
・そのため IntakeMint は、オンライン中は入力のたびに自動でサーバーへ保存します。
  端末内の下書きは「オフラインの間だけの一時保存」とお考えください。
・Web Push 通知は使っていません（通知は担当者画面内の通知とメールが基本です）。
・iOS のバージョンによって、カメラ起動などの挙動が異なるという情報があります（実機確認を推奨）。
（出典：SOURCE_NOTES.md「13. iOS Safari 上の PWA 制約」。確認日 2026-10-03）


■ 動作確認の範囲（重要）

・スマホ表示の自動テストは、Playwright の Chromium に端末プロファイル
  （iPhone 13 / Pixel 7 / iPad (gen 7)）を適用した「エミュレーション」でのみ行っています。
・実際の iPhone（Safari / WebKit）・Android 実機での確認は行っていません。
・ホーム画面への追加、カメラ撮影、HEIC写真のアップロード、オフライン時の挙動などは、
  販売・本番公開の前に、購入者様の責任で実機にて確認してください。
  確認をおすすめする端末：最新と1つ前の iOS の iPhone、代表的な Android 端末、iPad。
