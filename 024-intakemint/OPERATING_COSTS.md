# OPERATING_COSTS — 運用コスト試算

> 確認日：2026-10-03。単価の出典と信頼度は `research/pricing_inputs.json` と `SOURCE_NOTES.md` を参照。
> **official** = 公式ページで確認、**secondary** = 公式ドメイン検索結果または第三者記事（公式ページはプロキシで取得不可）。
> **販売前・契約前に、すべての単価を各社の公式料金ページで再確認すること。**

## 1. 前提

| 項目 | 前提 |
|---|---|
| 為替 | 1 USD = 150 JPY（仮置き） |
| 平均ファイルサイズ | 2 MB（写真・PDF混在） |
| 保存期間 | 12か月（アーカイブ後 `retentionDays` 既定365日で自動削除）→ 定常状態のストレージ = 月間アップロード量 × 12 |
| バックアップ | オブジェクトを1コピー追加保存（×2） |
| AI | 1案件あたり AI分析6回、1回 入力≈3,000 / 出力≈600 tokens |
| OCR/Vision | 任意機能。PDF/画像の50%を1ページとして処理（基盤では未接続。接続時の試算） |
| メール | 1案件あたり 6通（リンク・確認コード・リマインド） |
| 基本料 | 〜100案件/月：Supabase Pro $25（Micro compute込み）+ Render Starter $7 = **$32**。1,000案件/月：DB Small相当 + アプリ2台で **$65** 程度 |

使用単価（USD）：
- Cloudflare R2：$0.015/GB-月（10GBまで無料）、Class A $4.50/100万、エグレス無料（official）
- Claude Haiku 4.5：入力 $1 / 出力 $5 per 1M tokens、Sonnet 5.5：$2 / $10（official）
- OCR（Google Vision / Textract Detect / Azure Read）：$1.5 / 1,000ページ（secondary）
- Amazon SES：$0.10 / 1,000通（secondary。2026-07-21以降の新規アカウントは無料枠なし）

読み方：
- **小規模（〜100案件/月）では基本料（DB+ホスティング）が支配的**。AI・ストレージは数ドル。
- 1,000案件/月・200ファイル/案件ではストレージ（定常4.7TB）とOCRが主要コスト。保存期間の短縮（例：180日）でストレージはほぼ半減。
- 既定の AI は **ローカル判定（外部送信なし・API費用0）**。外部AIを有効にした場合のみ AI 列が発生。
- AWS S3 + エグレスを使う場合は、ダウンロード量に応じ $0.09/GB のエグレスが加算（R2は無料）。

## 3. コンポーネント別メモ

| 区分 | 既定（同梱） | 本番候補 | コスト要因 |
|---|---|---|---|
| DB | PGlite（開発・デモ・単一ノード） | PostgreSQL（Supabase / Neon / RDS） | compute時間・ストレージ |
| Object Storage | ローカルFS | R2 / S3 / B2（`S3_*` 環境変数） | GB-月・操作数・エグレス |
| AI | ローカル判定（外部送信なし） | Anthropic Claude（`AI_PROVIDER=anthropic`） | tokens |
| OCR/Vision | 未接続（抽出は text/csv のみ） | Vision / Textract / Azure | ページ数 |
| Email | outbox-local（実送信なし） | Resend（`EMAIL_PROVIDER=resend`）/ SES | 通数・月額プラン |
| Jobs | DBキュー（同一プロセス worker） | 同左（別プロセス化可） | DB負荷のみ |
| Malware scan | EICAR検出のみ | ClamAV（別プロセス・GPL）/ GuardDuty S3 | GB・オブジェクト数 |
| Backup | ZIPエクスポート | ZIPをR2等へ保存 + DBのPITR | ストレージ |
